# SmallConvert-Your-Local-Image-Converter
SmallConvert is a simple, local image converter program supporting conversion to .docx, .pdf, .jpg and .png from a wide variety of file types. It runs as a standalone executable on your computer and supports Windows, Linux and Mac.
Supports conversion from .pdf, .docx, .png, .jpg, .svg, .webp, .bmp and Markdown.
